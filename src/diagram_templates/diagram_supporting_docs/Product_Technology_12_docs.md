# Technologies Used in the Tech Stack

## Application & UI
- **.NET 8 (C#)**   
- **JavaScript + jQuery**  
- **ASP.NET Web Forms (.NET Framework 4.0)** 

## Mobile
- **Flutter** – planned mobile application framework (iOS/Android)  

## APIs & Services
- **.NET 8 REST APIs** – JSON-based endpoints  
- **Python services** – specialized backend processing/services  

## Workflow / Job Scheduling (Workflow Engine)
- **Hangfire (SQL Server-backed)** – background jobs, long-running tasks, scheduling, retries (exports, report generation, file processing)  

## Data Platform
- **Primary database: Microsoft SQL Server (AWS RDS)** – operational and reporting data, stored procedures  

## Data Warehouse
  - **Azure Data Factory** for ETL  
  - **Azure SQL**

## Reporting / BI
- **Crystal Reports** – report templates, rendering, export  
- **Power BI** (if used for dashboards/analytics) – reporting and visualization  

---

## Monitoring / Logging / Observability
- **Datadog** – APM/monitoring, dashboards, alerting  
- **AWS CloudWatch** – logs, metrics, infrastructure monitoring  

## Security / Identity
- **SAML 2.0** – enterprise federated SSO with customer identity providers  
- **OAuth 2.0 bearer tokens** – API authentication/authorization  
- **RBAC** – role-based access control enforced in application  

## Data Access
- **Entity Framework + LINQ** – ORM/data access  
- **SQL Stored Procedures** – optimized queries and database operations  

## Caching
- **.NET MemoryCache** – in-memory caching for frequently used reference/config data
